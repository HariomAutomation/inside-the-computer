# 24 Master Curriculum Modules — Full CS Degree Level Map

A comprehensive 2-3 month degree-level curriculum spanning 24 Master Modules from semiconductor physics to LLM inference engines.

---

## ⚡ PART 1: SILICON SEMICONDUCTORS & PHYSICAL PHYSICS (Weeks 1-2)
1. **Module 1: Atomic Physics & Charge Carriers** (Electrons, Silicon Crystal Lattice, Doping P-Type & N-Type)
2. **Module 2: MOSFET Transistors & CMOS Switching** (Gate Oxide, Source/Drain, NMOS vs PMOS, Threshold Voltage $V_{th}$)
3. **Module 3: Voltage Margins & Digital Abstraction** (Analog Voltages 0V-5V, Noise Margins 0.8V-2V, Binary 0 and 1)

---

## 🧮 PART 2: BINARY MATH, ENCODINGS & BOOLEAN ALGEBRA (Weeks 3-4)
4. **Module 4: Binary Positional Notation & Two’s Complement** (Base-2, Base-16 Hexadecimal, Nibbles, Bytes, Signed Negatives)
5. **Module 5: Floating-Point Numbers & Character Encodings** (IEEE 754 Sign/Exponent/Mantissa, ASCII, UTF-8, UTF-16 Unicode)
6. **Module 6: Boolean Algebra & Logic Optimization** (Truth Tables, Boolean Laws, De Morgan’s Theorems, Karnaugh Maps K-Maps)

---

## 🧱 PART 3: COMBINATIONAL & SEQUENTIAL CIRCUITS (Weeks 5-6)
7. **Module 7: Digital Logic Gates in Silicon** (7 Logic Gates NOT, NAND, AND, NOR, OR, XOR, XNOR, Transistor Counts)
8. **Module 8: Binary Adders & Carry Lookahead** (Half Adder, Full Adder, Ripple Carry Delay, Carry Lookahead Adders CLA)
9. **Module 9: Multiplexers, Demultiplexers & Decoders** (MUX 2:1, 4:1, 8:1, DEMUX, 3-to-8 Decoders, Tri-State Buses)

---

## 💻 PART 4: MICROPROCESSOR ARCHITECTURE & CPU CORE (Weeks 7-8)
10. **Module 10: Latches, Edge-Triggered Flip-Flops & Registers** (SR Latches, D Flip-Flops, Setup/Hold Times, 8-Bit Registers)
11. **Module 11: The Arithmetic Logic Unit (ALU) & Status Flags** (Parallel ALU, Shift/Rotate, Status Flags: Z, V, N, C)
12. **Module 12: von Neumann & Harvard CPU Architecture** (Program Counter PC, IR, MAR, MDR, Control Unit CU Microcode)
13. **Module 13: 5-Stage Instruction Pipelining & Branch Prediction** (Fetch, Decode, Execute, Memory, Writeback; Hazards & Speculation)

---

## 💾 PART 5: MEMORY HIERARCHY, CACHE & STORAGE (Weeks 9-10)
14. **Module 14: Cache Memory Architecture & Coherence** (SRAM 6T Cells, L1/L2/L3 Caches, Set-Associativity, MESI Protocol)
15. **Module 15: Main RAM (DRAM) & SSD Storage Cells** (1T-1C DRAM Capacitors, Refresh Cycles, DDR5 Bus, NVMe NAND Flash)

---

## ⚙️ PART 6: MACHINE CODE, ASSEMBLY & COMPILERS (Weeks 11-12)
16. **Module 16: Instruction Set Architecture (ISA)** (RISC-V vs x86-64, Opcode Encodings, R/I/J Formats, Addressing Modes)
17. **Module 17: Assemblers, Linkers & Executable Formats** (Two-Pass Assembly, Symbol Tables, Object Files `.o`, ELF/PE Headers)
18. **Module 18: Compiler Pipelines & LLVM Code Optimization** (Lexer Tokenization, AST Parser, IR, LLVM Passes, Native CodeGen)

---

## 🖥️ PART 7: OPERATING SYSTEMS, VIRTUAL MEMORY & RUNTIMES (Weeks 13-14)
19. **Module 19: Operating System Kernels & System Calls** (Monolithic vs Microkernel, Syscalls `read/write/fork`, IRQ Traps)
20. **Module 20: Virtual Memory, Paging & MMU Hardware** (Memory Management Unit MMU, Page Tables, TLB Cache, Page Faults)
21. **Module 21: JavaScript Engine & Memory Runtimes** (V8 Engine, Call Stack, Memory Heap Allocation, Mark-Sweep GC, Event Loop)

---

## 🌐 PART 8: COMPUTER NETWORKING, BROWSERS & WEB (Weeks 15-16)
22. **Module 22: Web Browser Rendering Engine Pipeline** (HTML Tokenizer, DOM, CSSOM, Render Tree, Layout Reflow, Paint, GPU Compositing)
23. **Module 23: Computer Networking & Web Stack** (OSI 7 Layers, TCP/IP Sockets, DNS Lookup, TLS Handshake, HTTP/3 QUIC)

---

## 🤖 PART 9: ARTIFICIAL INTELLIGENCE, DEEP LEARNING & LLMs (Weeks 17-18)
24. **Module 24: Neural Networks, Transformers & LLM Inference** (Perceptrons, Backprop, Multi-Head Self-Attention $Q,K,V$, Tokenizers, Autoregressive LLM Sampling)
