# Contributing to Inside the Computer

We welcome contributions from developers, educators, hardware engineers, and students worldwide!

## 🚀 How to Contribute

1. **Pick an Issue**: Check out our open issues or look for `good first issue` tags.
2. **Fork & Branch**: Create a feature branch off `main` (`git checkout -b feature/my-new-sim`).
3. **Follow Coding Standards**: Ensure code adheres to `/docs/03-development/CODING_STANDARDS.md`.
4. **Definition of Done (DoD)**:
   - `npx tsc --noEmit` returns 0 errors.
   - `npx vite build` completes cleanly.
5. **Submit a Pull Request**: Include a detailed description of your changes.

Thank you for helping build the world's best open-source CS visual learning engine!
